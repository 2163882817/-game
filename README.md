# 高性价比人生 · 原生微信小程序前端

根据功能需求文档、开发文档和“完善后设计稿”V6 搭建。使用原生 WXML / WXSS / JavaScript，无框架、无运行时 npm 依赖。

## 在微信开发者工具中运行

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选本文件所在目录（不是 `miniapp` 子目录）。根目录已提供 `project.config.json`，自动识别 `miniapp/`。
3. 当前 AppID 为 `touristappid`，用于本地体验。若你的工具不支持游客模式，使用你自己的测试号或小程序 AppID。
4. 点击“编译”。从首页开始，完成引导后即可掷骰游玩。无需构建 npm 或启动后端。
5. 真机预览、好友分享及正式上传需要你自己的有效 AppID、微信登录与开发权限。

没有更改本机开发者工具的安全设置。当前工具的服务端口关闭，因此本次未通过 IDE 自动化运行模拟器，也未完成 iOS / Android 真机视觉验收。

## 已搭建的前端

- 首页、统一初值与三步引导、继续进度和重新开局确认。
- 16 格闭环棋盘、资源条、掷骰及逐格移动、跳过动画、格子规则查看。
- 生活事件选择、资源不足禁用说明、资产购买、保障选择、回合结果与可折叠解释。
- 资产列表、升级、出售二次确认、固定收益；困境援助、资产出售及差额减免。
- 指南搜索、主题和证据筛选、收藏、详情、复制出处、无结果状态。
- 四段阶段主线与报告、四种条件结局、完整经历、历史档案、八个探索成就。
- 主动分享入口、反馈本地保存与手动复制、规则、保存失败与重试页面。

共享组件位于 `miniapp/components`；纯规则引擎位于 `miniapp/engine`；演示内容位于 `miniapp/content`；双槽校验存储位于 `miniapp/services`。页面只发出命令并显示快照。

## 数据与规则边界

本次交付是可联调、可完整游玩的前端体验版，不是正式上线内容包。

- 内置 8 个原创演示情境、4 段阶段主线、8 条示范指南，尚未达到正式内容目标的 60 个事件、40 条知识。
- 所有指南显示“待审核”，没有伪造来源提交、证据等级或审核结果。正式内容需逐条核对、归因、锁定来源版本，再替换内容包。
- 演示固定使用 `demo-0.1.0`；存档锁定该版本。未知内容版本会拒绝结算，不能直接删掉仍被旧局引用的内容包。
- 开发文档第 11 节待确认规则采用临时演示口径：24 次掷骰，阶段主线额外出现；重复落在已持有资产不收费；所有等级暂按 ¥1,500 回收；每处每回合最多升级一次；恢复路径由玩家选择。均未视为已批准上线规则。
- 对局、历史、成就、收藏及反馈分别本地保存，无跨设备同步。重要游戏操作保存失败会阻断继续，并可重试同一份快照。
- 反馈未接外部服务；分享使用微信原生好友分享，不含生成图片或朋友圈海报导出。
- 内容审核后台、远程内容分发、服务端反馈和统计未包含在本次前端中。

## 检查

需要 Node.js 20 或更新版本，不需要 `npm install`。

```powershell
npm test
npm run check
npm run check:content
```

内容基础校验检查当前内容结构、事件/主线/知识/成就 ID、阶段与知识引用、选项数量、成本/结果文案，以及资源效果字段和数值；`npm run check` 已包含这一检查。

阶段覆盖校验要求四个有名称且名称不重复的阶段，每阶段至少一个普通事件、恰好一个符合当前引擎 ID 约定的主线；每个事件（含主线与保底）在零现金、精力/健康/保障均为 100 的基线状态下，至少有一个按实际资源效果可执行的选项。此检查不等于所有低资源组合和结构化前置条件已验证。

已接入四阶段机会格保底：`fallbackMap[阶段].event` 指向独立的 `fallbackEvents`。普通事件池为空或没有任何可执行选项时，引擎使用同阶段保底，选中 ID 随掷骰承诺保存，恢复后不重抽；普通事件仍优先未见内容，全部见过后按现有演示规则复用。校验会阻断缺失/跨阶段映射、重复 ID，以及缺少全零资源可执行选项的保底。当前新增 4 条原创演示保底，使演示内容合计为 16 个条目（8 普通、4 主线、4 保底）；不代表正式 60 事件目标已完成。结构化前置条件、权重和非机会格保底配置仍待后续实现。

`npm run check:content:release` 额外检查正式内容数量、演示版本标记、配置化结局、知识证据及来源提交占位。当前演示包运行此命令应失败，这是预期的阻断行为。此命令只是基础发布门禁，不替代条件可达性、保底覆盖、完整来源审核、内容管理及版本兼容验收。

测试覆盖起点工资与收益、重复提交、资源边界、升级次数、现金不足、低状态恢复、四段主线、四种结局、100 个种子的完整 24 回合，以及双槽回退、重开隔离、应用保存失败重试。

`check` 校验全部脚本/JSON、路由与事件绑定，并在本机存在微信工具编译器时调用真正的 `wcc.exe`、`wcsc.exe`。其他安装位置可通过 `WECHAT_COMPILER_DIR` 指定。

正式验收仍需：微信开发者工具运行与小屏/大字体检查、iOS/Android 真机、有效 AppID 分享、完整审核内容、待确认规则冻结、内容版本迁移策略与微信平台发布审核。
